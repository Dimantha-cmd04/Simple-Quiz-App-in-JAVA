# Simple Quiz App in Java

## 📌 Description

Simple Quiz App is a console-based Java application that allows users to answer multiple-choice questions and receive their final score.

This project was created to practice basic Java programming concepts and build a simple interactive application.

## ✨ Features

- Multiple-choice questions
- 10 Java-related questions
- User input using Scanner
- Answer validation
- Score calculation
- Correct and incorrect answer feedback
- Answer explanations
- Input validation
- Exception handling

## 🛠️ Technologies Used

- Java
- Java Scanner
- Arrays
- Loops
- If-Else Statements
- Exception Handling

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/Dimantha-cmd04/Simple-Quiz-App-in-JAVA.git
```

### Step 2: Open the Project

Open the project in:

- Visual Studio Code
- IntelliJ IDEA
- Eclipse
- NetBeans

### Step 3: Compile the Program
    javac SimpleQuizApp.java
### Step 4: Run the Program
    java SimpleQuizApp

### 🎮 How the Application Works
- The application displays a question.
- Three answer options are displayed.
- The user selects an answer.
- The application checks the answer.
- The user receives feedback.
- The score is updated.
- After all questions, the final score is displayed.
